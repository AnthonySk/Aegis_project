   masse cible du drone ;

   autonomie visée.
2. Estimation de masse

Élément	Masse

Contrôleur AEGIS	xxx g

Caméra	xxx g

Masse totale :

M_total = ... kg
3. Calcul de poussée nécessaire

Formule :

Poussée totale = masse × ratio

Exemple :

Drone : 1,5 kg
Ratio choisi : 4

Poussée nécessaire :
1,5 × 4 = 6 kg
4. Répartition par moteur

Pour un quadricoptère :

Poussée moteur = poussée totale / 4

Exemple :

6 kg / 4 = 1,5 kg par moteur
5. Choix moteur + hélice

Tableau :

Moteur	KV	Hélice	Batterie	Poussée
Exemple	900KV	10x5	4S	1,5kg
6. Validation expérimentale

Tests :

poussée réelle ;
courant consommé ;
température moteur ;
autonomie.
